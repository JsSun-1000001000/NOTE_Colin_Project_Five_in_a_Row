# QT信号与槽

qt第五个参数是默认参数 不写也能运行

涉及到多线程的知识

## 使用信号和槽的时候要注意什么

- 严格情况下，信号与槽的参数个数和类型需要一致
- 在使用信号与槽的类中，必须在类的定义中加入宏Q_OBJECT
- ==**（单线程）**==当一个信号被发射时，与其关联的槽函数通常被立即执行，就像正常调用一个函数一样。只有当信号关联的所有槽函数执行完毕后，才会执行发射信号处后面的代码
## 特殊知识

- QT的控件只能是主线程控制，如果新建的线程控制控件会产生问题，崩溃
- QT新建的线程（如网络recv线程）如果要对界面控件进行控制，只能通过信号槽完成

## connect函数的第五个参数

Qt supports these signal-slot connection types:

- [Auto Connection](https://doc.qt.io/qt-6/qt.html#ConnectionType-enum) (default) If the signal is emitted in the thread which the receiving object has affinity then the behavior is the same as the Direct Connection. Otherwise, the behavior is the same as the Queued Connection."
若信号在接收对象所属线程中发出，则行为与DirectionConnection相同，否则行为与QueuedConnection相同

- [Direct Connection](https://doc.qt.io/qt-6/qt.html#ConnectionType-enum) The slot is invoked immediately, when the signal is emitted. The slot is executed in the emitter's thread, which is not necessarily the receiver's thread.
信号发出时立即调用槽函数。槽函数在信号发出线程中执行，该线程未必是接收对象的线程。

- [Queued Connection](https://doc.qt.io/qt-6/qt.html#ConnectionType-enum) The slot is invoked when control returns to the event loop of the receiver's thread. The slot is executed in the receiver's thread.
当控制权返回接收者线程的事件循环时调用槽函数。槽函数在接收者线程中执行。

- [Blocking Queued Connection](https://doc.qt.io/qt-6/qt.html#ConnectionType-enum) The slot is invoked as for the Queued Connection, except the current thread blocks until the slot returns. 调用方式与QueuedConnection相同，但当前线程会阻塞直至槽函数返回。
    
    **Note:** Using this type to connect objects in the same thread will cause deadlock. 在同一线程中使用此类型连接对象将导致死锁。
    
- [Unique Connection](https://doc.qt.io/qt-6/qt.html#ConnectionType-enum) The behavior is the same as the Auto Connection, but the connection is made only if it does not duplicate an existing connection. i.e., if the same signal is already connected to the same slot for the same pair of objects, then the connection is not made and connect() returns .`false`
行为与AutoConnection相同，但仅在不重复现有连接时建立连接。即若同一信号已连接至同一对象对的同一槽位，则不会建立连接，connect() 返回 `false`。

The connection type can be specified by passing an additional argument to [connect](https://doc.qt.io/qt-6/qobject.html#connect)(). Be aware that using direct connections when the sender and receiver live in different threads is unsafe if an event loop is running in the receiver's thread, for the same reason that calling any function on an object living in another thread is unsafe.

## 多线程

线程1：AA——SIG——BB
线程2：CC SLOT

direct connection：AA SIG CC BB
queued connection：AA BB——CC（同时）
blocking queued connection：AA CC BB 不在一个线程里面

## 自定义参数

在conect连接前添加声明：

```cpp
#include <QMeteType>
qRegisterMetaType<MyClass>("Myclass");
```

## 总结

1. 严格的情况下，信号与槽的参数个数和类型需要一致
2. 使用信号槽，必须是QObject子类
3. 在使用信号与槽的类中，必须在类的定义中加入宏Q_OBJECT
4. 一个信号可以连接多个槽
5. 多个信号可以连接同一个槽
6. 一个信号可以连接另外一个信号
