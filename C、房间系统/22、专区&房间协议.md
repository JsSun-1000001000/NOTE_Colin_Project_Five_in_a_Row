# 专区

1. ==**进入专区**==：进入大厅选择专区，跳转到对应专区，如果退出专区，应该回到大厅选择专区
2. ==**更新专区房间信息**==：进入专区，进入的是哪个专区应该首先发送给服务器，服务器保存所在的专区状态，同时客户端也应该保存此状态，并且应该开启计时器每过一段时间刷新各个房间玩家的信息，比如每秒一次，为了方便起见120个房间，每个房间统计人数即可，每次返回结果，是一个数组，收到解析，然后给每个房间界面更新
3. ==**加入房间**==：接下来就是加入房间，因为房间已经是存在的了（快速匹配以后再说），根据房间的状态情况，直接加入，暂时不带围观功能，那么一个房间就是2人，第一个进入房间的人是房主，他能决定时候开局，第二给进入的人只能准备，并且可以规定，只要房主退出房间，该房间的其他人直接退出，那么玩家是否是房主这个标志位要记录
4. ==**退出房间**==：根据上面的描述离开房间，有两个逻辑分支，第一是房主，如果是那么需要解散房间，所有人推出；如果不是房主，那么就是退出，然后通告所有人，所有人收到后，更新画面
