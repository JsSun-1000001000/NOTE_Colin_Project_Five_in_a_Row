## MD5部分

![[G、项目整理图示/md5.png]]
md5 名字 信息摘要算法 第五代，属于Hash算法。对任意长度信息加密成128位摘要
[MD5加密概述，原理及实现-CSDN博客](https://blog.csdn.net/Oliver_xpl/article/details/90214896)
### 特点
不可逆，理论上一个md5可以对应多个原文一共 $2^{128}$ 种可能。
可以被彩虹表破解
### md5性质
1. 压缩性：长度都一样
2. 容易算
3. 抗修改：改一个就不一样了
### 缺点
1. 可以破解，搜集结果
2. 可以加盐让他更安全
### 算法原理和步骤
1. 先填充数据，填到多长？对512取模得448
2. 怎么填充？在消息后填充，第一位1，后面为0
3. 填充后在加上远信息长度；能存多少？264，超过的话用低64位的值
4. 以上三步完成后消息长度是512的整数倍
5. 给四个常数，叫链接变量（注意标准的和小端模式的不一样）
  物理顺序：
  A = 0×01234567 
  B = 0×89ABCDEF 
  C = 0xFEDCBA98 
  D = 0×76543210
  和小端模式：
  A = 0x67452301
  B = 0xEFCDAB89
  C = 0x98BADCFE
  D = 0x10325476

**小端模式**在现代计算机中更为常见，尤其是在x86和ARM架构的处理器中。小端模式将数据的低位字节存储在低地址，高位字节存储在高地址。这种方式符合处理器从低位到高位处理数据的逻辑，因此在大多数通用计算机和嵌入式设备中被广泛采用。

**大端模式**主要用于网络通信和某些特定的硬件协议中。例如，TCP/IP协议规定使用大端模式（也称为网络字节序）。这种方式将高位字节存储在低地址，更符合人类从左到右的阅读习惯，因此在网络传输和某些文件格式（如GIF、PNG）中具有优势。

6. 用4个非线性函数 四种操作 算64次循环，分成4轮，每轮16次，每轮使用ff，gg，hh，ii中的一种，一轮中，abcd使用顺序轮转

然后需要用到4个非线性函数
F(X,Y,Z)=(X & Y) | ((~X) & Z);
G(X,Y,Z)=(X & Z) | (Y & (~Z));
H(X,Y,Z)=X ^ Y ^ Z;
I(X,Y,Z)=Y ^ (X | (~Z));
(&是与, |是或, ~是非, ^是异或)

然后是4种操作
FF(a,b,c,d,Mi,s,tj)  表示a=b+((a+(F(b,c,d)+Mi+tj)<<< s)
GG(a,b,c,d,Mi,s,tj) 表示 a=b+((a+(G(b,c,d)+Mi+tj)<<< s) 
HH(a,b,c,d,Mi,s,tj) 表示 a=b+((a+(H(b,c,d)+Mi+tj)<<< s) 
II(a,b,c,d,Mi,s,tj)   表示a=b+((a+(I(b,c,d)+Mi+tj)<<< s) 
其中Mi表示消息的第i个子分组（从0到15，共16个），<<< s表示循环左移s位
常数tj为： 
在第j步中，tj是4294967296\*abs(sin(j))的整数部分，j的单位是弧度。
(4294967296是2的32次方)
亦可用 0x100000000UL \* abs(sin((double)j)) 计算
x循环左移s位:
( s << x ) | ( s >> (32 - x) )

例如第一轮:

第一次计算 FF(a,b,c,d,M0,s,t1)
                   a = a+(F(b,c,d)+M0+t1);
                   a = ( s <<a ) | ( s >> (32 - a) );
                   a = a + b;

第二次计算 FF(b,c,d,a,M1,s,t2)
                   b = b+(F(c,d,a)+M1+t2);
                   b = ( s <<b ) | ( s >> (32 - b) );
                   b = b + c;
